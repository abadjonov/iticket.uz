# iticket.uz

Turli xil eventlarga (konsert, teatr, sport, stand-up va h.k.) online ticket sotadigan platforma. Backend Development kursi doirasidagi o'quv/amaliyot loyihasi, hozircha MVP (Minimum Viable Product) bosqichida.

**Tech stack**: Python · FastAPI (async) · SQLAlchemy (async) · PostgreSQL

## Hujjatlar

To'liq mahsulot va texnik spetsifikatsiya uchun [`docs/00-index.md`](docs/00-index.md) ga qarang — u yerda PRD, arxitektura, DB schema, API spetsifikatsiya, to'lov integratsiyasi, QR check-in, deployment reja va MVP roadmap keltirilgan. Hujjatlar ataylab sodda tutilgan — murakkabroq mavzular har bir faylda "🎓 Bonus" deb belgilangan.
